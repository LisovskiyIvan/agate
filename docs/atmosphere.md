# Атмосфера: аналитическое физическое небо (opt-in)

Дата: 11.10.2026. Статус: v1 готово, по умолчанию выключено.

## Что это

Опциональная аналитическая модель неба (Preetham-класс), которая из высоты
солнца и мутности выводит согласованную тройку:

- цвет/интенсивность солнца (ослабление Бугера — Ламберта — Бера);
- яркость купола неба по направлению взгляда (распределение Переса);
- полусферический ambient (небо/земля) + тинт тумана под тот же горизонт.

Ручные крутилки (цвет солнца, ambient, туман, шафты) остаются и выигрывают
там, где их оставили: модель **даёт значения, а не заставляет**.

## Модель (честно)

- Функциональная форма Переса точная; коэффициенты зависимости от мутности
  и рампы зенит/горизонт — inline-аппроксимация в духе Preetham et al. 1999,
  НЕ сертифицированная реализация (таблицы Hosek-Wilkie по памяти корректно
  не восстановить — взяли более простую модель, которую можно проверить).
- Воздушная масса — Кастен–Янг, с полом (конечна за горизонтом).
- Солнечный диск — HDR-добавка в куполе (под bloom), порог — косинус
  углового радиуса солнца.
- CPU: `src/postprocess/sky.zig`, golden-тесты `src/postprocess/sky_tests.zig`
  (зенит/горизонт, монотонность покраснения, энергосанити, направление
  мутности, фиксированные значения).
- GPU: тот же набор формул в `src/shaders/skybox.glsl` (аналитическая ветка
  за `sky_ctrl.x`; расхождения float-точности с CPU — норма).

## Связка (только значения, без новых лейнов)

Модель пишет в СУЩЕСТВУЮЩИЕ юниформ-лейны, раскладка не менялась:

- `sun_color`/`sun_intensity` (+ зеркало primary sun, directional slot 0 —
  только если слот живой, отсутствующее солнце не выдумывается);
- hemi `diffuse`/`ground_color` (направление hemi остаётся ручным);
- `fog_color.rgb` (флаг тумана и остальные входы — ручные, как были);
- передача солнца в шафты — через уже существующий `sun_dir`.

Новый юниформ-блок `sky_params` есть только у skybox-шейдера
(`sky_sun`, `sky_ctrl`, `sky_sun_color`); при нулях — бит-идентичный
текстурный путь. Во frame/postprocess-лейнах новых слотов нет — и это
намеренно (APPENDED-LAST дисциплина не потревожена).

## Включение

- `Scene.phys_sky: SkyOptions` (по умолчанию всё OFF — кадры бит-идентичны).
  `drive_sun`/`drive_ambient`/`drive_fog` (default true) — порученные выходы;
  `sun_elevation_deg`/`sun_azimuth_deg` (null = держать `sun_dir` сцены);
  `dome_enabled` — рендерить аналитический купол вместо кубемапы.
- q0: `AGATE_Q0_PHYS_SKY=1` (+ `AGATE_Q0_SKY_TURBIDITY`,
  `AGATE_Q0_SUN_ELEV`/`AGATE_Q0_SUN_AZIM` для итераций времени суток).
  Дефолт q0 — ручной вид владельца, не тронут.

## Что вне v1 (открыто)

- Сертифицированные коэффициенты Preetham/Hosek-Wilkie, отдельный half-res
  aerial-perspective проход.
- Пробники при куполе пекут аналитический рендер напрямую (консистентно),
  отдельного IBL-бейка не требуется.

## Sky v2: облака + ночное небо (opt-in внутри купола)

Дата: 11.10.2026. Статус: готово, по умолчанию выключено.

Слои живут ТОЛЬКО в skybox-визуале (`skybox.glsl`, ветка за `sky_ctrl.x`);
связка солнце/ambient/туман не тронута (ночь НЕ диммит свет и туман —
это осознанно, см. ограничения).

### Облака: 2D FBM-слой на куполе, не волюметрика

- Value-noise FBM (4 октавы, детерминированный хеш, без текстур) на
  планарной проекции `uv = (dir.xz / (y + 0.15) + wind*time) * scale`.
- Маска покрытия — тот же smoothstep-рамп, что CPU `cloudMask`
  (`smoothstep(1-cov, 1-cov+0.25, n)`); `coverage = 0` — чистое небо точно.
- Горизонтальное сжатие: слой живёт выше пригоризонтной полосы и гаснет
  в неё (`smoothstep(0, 0.25, y)`, сила — `horizon_fade`).
- Освещение: подсвеченная сторона — солнечный тинт, затенённая — ambient
  неба; ночью солнечный вклад уступает лунному тинту (приближение).
  Серебристая кайма — форвардный лепесток `pow(cos,6)` к солнцу/луне
  (фейк: ни фазовой функции, ни самозатенения).
- Анимация — адвекция ветром (`wind_dir_deg`, `wind_speed`, часы `time_sec`
  захватываются снапшотом; q0 копит `dt` пока включён phys sky).
- CPU: `CloudOptions` в `SkyOptions` (coverage, scale, wind_dir_deg,
  wind_speed, brightness, silver_strength, horizon_fade) + клампы/санитайз,
  golden-тесты в `sky_tests.zig` на каждое выведенное значение.

### Ночь: звёзды + аналитическая луна

- `nightAmount`: 0 днём (солнце выше ~+2°), 1 ночью (ниже ~−6°), гладко
  между; `night.enabled = true` форсирует полную ночь для дневных итераций,
  `night.auto = false` отключает автовключение.
- Дневное небо тонет к почти-чёрному синему; горизонт держит остаток
  `horizon_dim` (0 = кромешная тьма, 1 = дневной горизонт).
- Звёзды — порогованный хеш по квантованному направлению (плотность
  `star_density`, HDR-гейн `star_intensity`, дешёвое мерцание синусом).
- Луна — аналитический диск (всегда полная: фазового члена нет),
  HDR-гейн `moon_intensity` под bloom + узкое гало; направление —
  `moon_elevation/azimuth_deg` либо дефолт (35°, 200°); радиус —
  `moon_radius_deg` через `moonDiscCos`.
- CPU: `NightOptions` в `SkyOptions` + `nightAmount`/`moonDir`/`moonDiscCos`
  с golden-тестами.

### Юниформы и флаги

- Всё внутри существующего блока `sky_params` (binding 2, APPENDED:
  `sky_cloud`, `sky_cloud2`, `sky_night`, `sky_night2`, `sky_moon`);
  старые смещения не сдвинуты. Нулевые extras — бит-идентичный дневной
  купол (CPU `analyticParamsFull` == `analyticParams`, тест пинает);
  текстурный путь при выключенном phys sky — как был.
- Снапшот несёт готовый `sky_params` (считается только при живом куполе).
- q0: `AGATE_Q0_CLOUDS=1` (+ `AGATE_Q0_CLOUD_COVERAGE`,
  `AGATE_Q0_CLOUD_SCALE`, `AGATE_Q0_WIND`, `AGATE_Q0_WIND_DIR`),
  `AGATE_Q0_NIGHT=1` (форс ночи; автоночь — просто `AGATE_Q0_SUN_ELEV`
  ниже горизонта, отдельных флагов для звёзд/луны нет).

### Честные ограничения v2

- Облака — плоский 2D-слой на куполе: нет объёма, самозатенения,
  рассеяния внутри облака, отбрасываемых теней; кайма — фейк.
- Звёзды — процедурный хеш (не каталог), мерцание — синус, не сцинтилляция.
- Луна всегда полная, без фазы и без лунного света на сцене (только диск
  на куполе; свет/ambient/туман ночью не меняются).
- Ночь/облака — только визуал купола: IBL/пробы пекут тот же рендер
  (консистентно), но освещение сцены под ночь не адаптируется.
