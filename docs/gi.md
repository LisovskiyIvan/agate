# DDGI v1 (spike)

Спайк диффузного GI на пробной сетке поверх прокси-сцены из AABB
(сценарий 3 из Q3 после выбора источника лучей: ни BVH, ни SDF —
плоский список боксов). Статус: opt-in, по умолчанию выключено и
побитово неотличимо от выключенного (доказано попиксельным сравнением
кадров q0: baseline c26511e vs сборка с DDGI-выкл — средний diff
0.03 lsb, см. «Проверено» ниже).

## Модель

Статическая мировая сетка зондов поверх сценного объёма
(`origin`/`extent`/`counts`, counts клампятся в `gi.ddgi.clampedCounts`,
произведение ≤ 256). Каждый зонд — тайл 8×8 текселей RGBA16F-атласа,
один тексель — одно направление (октаэдральное кодирование, CPU-зеркало
`gi.ddgi.probeRayDir`/`octEncode`/`octDecode`, семплирующая сторона —
`shaders/common/ddgi_sample.glsl`).

Обновление — фрагментный проход без compute (полка sokol/D3D11):
`passes.DdgiPass` рисует один фулскрин-треугольник в атлас с LOAD
(атлас переживает кадры, нужен для round-robin). Луч марширует список
прокси (slab-тесты, жёсткая граница `MAX_PROXIES = 64` + ранний выход по
загруженному числу):

- промах — полусферический ambient сцены (те же hemi-полосы, та же
  модель, что `common/hemi.glsl`);
- попадание — albedo прокси × прямое солнце, если вторичный марш к
  солнцу не заблокирован (только прокси, без чтения shadow-map) +
  полный hemi-ambient (аналитический, без окклюзии — как PBR-hemi);
- один баунс, альфа всегда 1.

Нормаль попадания — нормаль грани AABB (пересчёт по точке входа, не
интерполяция). Попадания ближе `SELF_HIT_MIN_T = 5см` игнорируются
(защита от самопересечения зондов, лежащих на поверхностях).

Семплирование — один тап на зонд вдоль нормали поверхности +
трилинейное смешивание 8 соседних зондов (`ddgiBounce`,
CPU-зеркало `gi.ddgi.probeBlend`; расхождение encode/decode ловит тест
`sample uv roundtrips`). Это диффузный прокси, НЕ интеграл по
полусфере: корректный вес ≈ 1/π, поэтому калибровочная интенсивность
q0 — 0.35 (≈1/π), атлас хранит сырые значения, интенсивность —
семплирующая сторона (как SSGI: композит масштабирует после денойза).

Бюджет: `probes_per_frame = 0` — вся сетка каждый кадр (1 draw);
иначе round-robin окно `gi.ddgi.budgetWindow`, латентность полного
обновления `convergeFrames` (ceil(P/B) кадров). q0: сетка 6×4×6 = 144
зонда, атлас 64×144, whole-grid.

## Прокси-сцена

Собирается из мешей сцены в момент снапшота (`packFrameSnapshot` —
под исключением build-фазы, рендер живых мешей не читает никогда):
мир-AABB (`getWorldBoundingBox`), albedo = базовый цвет PBR-материала
(шейдерные материалы — белые), дальше `sanitizeProxy` + `dedupeProxies`
(CPU, `gi.ddgi`, покрыты тестами):

- пропуск: скрытые, декали, прозрачные (blend), LOD-дети,
  невалидные боксы, инстансинг (v1 — явно вне скоупа);
- партикли — не меши, отсекаются конструктивно;
- тонкие слэбы (нулевая толщина по одной оси: стены/пол/панели) —
  валидные окклюдеры, slab-марш резолвит их точно; дропаются только
  точки/инверсии/NaN/гиганты;
- albedo клампится в [0,1]; ТЕКСТУРЫ ИГНОРИРУЮТСЯ (пол с чекером идёт
  белым базовым цветом — читает ярче своего среднего; осознанно).

Кап прокси — 64 в порядке мешей, дальше молча дропаются
(задокументированный режим отказа; q0 держит 9 из 10 мешей —
стеклянная панель прозрачная и вылетает корректно).

Неявного ground/backdrop-прокси не понадобилось: пол q0 — настоящий
меш и так входит в сцену.

## Путь интеграции: (a) PBR ambient

Выбран путь (a) — семплирование атласа в общем PBR ambient-блоке, а не
композит. Причина: в PBR-шейдере есть настоящие albedo, геометрическая
нормаль и metallic под рукой — bounce ложится как
`ddgiBounce * albedo * (1-metallic)` рядом с hemi-членом. Композитный
путь (b) потребовал бы восстанавливать albedo из освещённого цвета
(нет albedo-буфера в forward-композите) — это грубая аппроксимация
неизвестной честности; выигрыш (b) — один шейдер вместо трёх точек
вызова — не перевешивает.

Сантехника (a) по факту скромная и вся идёт существующими швами:

- `common/pbr_fs_bindings.glsl`: +2 строки (`ddgi_tex` view 22,
  `ddgi_smp` sampler 9 — следующие свободные слоты пула);
- `common/frame_view.glsl` + `FrameViewUniforms`/`FrameUniforms`/
  `FrameContext`: +4 vec4 strictly appended-last (нули при выкл);
- `common/ddgi_sample.glsl` — новый общий чанк (вся логика там);
  три мейна (pbr/skinned/instanced) — по ОДНОЙ строке у ambient-члена;
- `draw.zig`: Environment +2 поля (всегда валидные бинды: атлас или
  дефолтный белый) + 2 строки бинда в 3 сайтах
  (regular/hook-engine-template/instanced; runtime-external шейдеры
  слотов не декларируют — не тронуты);
- legacy-проводка (`LegacyFsParams`, 2560B) не тронута: legacy-шейдеры
  собираются из старых шаблонов, ddgi-полос там нет;
- шейдер семплирует только при `enabled == 1`, до первого fetch —
  ранний выход (выкл = побитово тот же путь).

Апдейт бежит PASS 1.75 в `frame_render` (до main pass — форвард
семплирует атлас того же кадра), вид отдаётся в Environment;
на renderReuse-переигровках рефреш скипается, вид persisted-атласа
продолжает раздаваться. Хук-engine-template материалы получают bounce
автоматически (тот же ambient-член базового шаблона); runtime-external
и unlit — нет. Зеркальные проба-капчи (probe_render строит свой
Environment без атласа) биндят дефолтный белый плейсхолдер через
fallback в точках бинда — капчи остаются легаси по дизайну v1.

## Light leaks и честные ограничения

- Нет релокации зондов: зонд внутри прокси видит albedo
  вмещающего бокса с дистанции SELF_HIT (калибровка q0 держит ~2 зонда
  внутри tall_box — эффект локальный и стабильный).
- Нет окклюзии ambient-члена (как PBR-hemi): bounce просачивается
  через тонкие стены — классический light leak, виден на границе
  комната/улица. Порог leak-а не тюнился (спайк).
- Один тап вместо интеграла: высокочастотный контент атласа
  (резкие тени от солнца в зондах) даёт алиасинг при движении;
  NEAREST + нет guard-полос (билинейник тёк бы через границы тайлов).
- Прокси-грубость: сферы/скошенная геометрия — боксами (замигает
  лишняя блокировка); текстуры игнорируются; инстансинг не собирается;
  кап 64 бокса.
- Цвет mostly-ахроматический на q0: доминирующий источник bounce —
  белый солнечный патч на белом (базовый цвет) полу; цветной вклад
  стен есть, но скромный (замер: грань бокса +16/+12/+22 lsb,
  см. ниже). Честный цветной bounce требует albedo с текстурами +
  больше зондов у стен — вне скоупа v1.
- WebGL-пол: блок fs_update — 202 vec4 (3×64 прокси + 10);
  минимум фрагментных юниформов GLES3 — 224. На D3D11/Metal запаса
  кратно; веб-пол не в гейтах спайка, но апдейт-шейдер туда впритык.

## Проверено

- `zig fmt --check`, `zig build test` (1667 passed / 6 skipped),
  `zig build`, `cd examples && zig build`, `cd examples && zig build test`.
- q0 120f default: PASS; q0 120f `AGATE_Q0_DDGI=1`: PASS, failures=0.
- `AGATE_HDR_FRAMES=120 hdr-showcase`: log_errors=0;
  `runtime-worker --frames 240`: PASS.
- Счётчики: DDGI-arm = +1 draw/кадр ровно (112→113), форвард-дро
  не меняются; апдейт = 1 draw независимо от бюджета.
- Пиксели (покадровое on/off, still-камера, оконный захват +
  чистый python PNG-дифф, методологический шум 0.30 lsb):
  выкл vs истинный baseline c26511e — 0.03 lsb среднего diff
  (0.14% пикселей > 6lsb — шум TAA/пыли между прогонами);
  вкл 0.35 vs выкл — 6.78 lsb, 33.1% пикселей (пол +18, грань
  бокса +16/+12/+22, задняя стена +4); вкл 1.0 — 13.76 lsb, 58%.
- AB `AGATE_Q0_AB=ddgi` (вкл/выкл блоками, medians/p95 в отчёте о
  прогоне; whole-grid 144 зонда на этом железе — дешевле 1мс,
  см. цифры в коммите).
